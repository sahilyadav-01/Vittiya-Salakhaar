## 🌟 Platform Overview

**Vittiya Salakhaar** is an Indian fintech and taxation platform designed to help individuals, freelancers, startups, and MSMEs understand and manage their financial requirements. 

The platform is founded on three core pillars:
1. **📚 Vittiya Gyaan (Learn)**: Jargon-free financial guides, explainers, regulatory updates, and a searchable A–Z financial dictionary.
2. **🧮 Vittiya Tools (Calculate)**: 13 live financial calculators with interactive SVG donut charts, presets, and instant side-by-side tax regime comparisons.
3. **💼 Vittiya Services (Get Expert Support)**: Transparent professional services covering Income Tax, GST, Bookkeeping, Payroll, Entity Registration, and Virtual CFO Advisory.

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer)
- npm (v9 or newer)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/sahilyadav-01/Vittiya-Salakhaar.git

# 2. Navigate to project directory
cd Vittiya-Salakhaar

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```
Open `http://localhost:3000` in your web browser.

### Production Build
```bash
npm run build
```
This generates an optimized production bundle inside the `dist/` folder ready for static hosting or cPanel upload.

## 🌐 GoDaddy & Domain Deployment Guide

### Option A: Free Hosting on Vercel / Netlify (Recommended)
1. Push this repository to GitHub.
2. Link the repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com) (auto-detects Vite).
3. In your GoDaddy DNS manager, point your domain:
   - **Type `A`**: Name `@` → `76.76.21.21` (Vercel)
   - **Type `CNAME`**: Name `www` → `cname.vercel-dns.com`

### Option B: GoDaddy Web Hosting (cPanel)
1. Run `npm run build` locally.
2. Log in to GoDaddy cPanel and open **File Manager**.
3. Upload all files from the generated `dist/` folder directly into `public_html/`.
4. The included `public/.htaccess` file ensures client-side routing works smoothly without 404 errors on page refresh.
